# QR-code-generator-

# 🔳 QR Code Generator

A simple and modern QR Code Generator built with **HTML**, **CSS**, and **JavaScript**. Generate QR codes instantly for URLs, text, phone numbers, emails, Wi-Fi credentials, and more.

---

## ✨ Features

- ⚡ Generate QR codes instantly
- 🌐 Supports URLs, text, phone numbers, emails, and more
- 📱 Responsive design for desktop and mobile
- 🎨 Clean and modern user interface
- ❌ Input validation
- 🔄 Generate unlimited QR codes
- 📥 Download generated QR code (if implemented)
- 🚀 Fast and lightweight
- 💻 No backend required

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- QR Code API / QR Code Library

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/qr-code-generator.git
```

### 2. Open the project

Simply open `index.html` in your browser.

Or use **VS Code** with the **Live Server** extension.

---

## 📖 How to Use

1. Enter any text or URL.
2. Click the **Generate QR Code** button.
3. Your QR code will appear instantly.
4. Scan it using any QR code scanner.
5. Download it if the download feature is available.
